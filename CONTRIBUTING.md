# Como contribuir

Obrigado por ajudar neste projeto!

## Antes de começar

1. Leia o README e confirme que está trabalhando no projeto correto.
2. Para mudanças importantes, abra uma Issue para discutir a proposta antes de programar.
3. Não envie senhas, tokens, chaves de API, dados pessoais ou arquivos locais privados.

## Fluxo de trabalho

1. Atualize sua cópia da branch principal (`main`).
2. Crie uma branch específica para a tarefa:
   - `feat/nome-da-melhoria` para funcionalidades;
   - `fix/descricao-do-bug` para correções;
   - `docs/descricao` para documentação.
3. Faça uma mudança pequena e focada.
4. Teste o que foi alterado e descreva o resultado.
5. Faça commits com mensagens claras, por exemplo:
   - `feat: adiciona filtro de tarefas`
   - `fix: corrige salvamento das tarefas`
   - `docs: explica como executar o aplicativo`
6. Abra um Pull Request para `main), explique o motivo da mudança e associe a Issue, se houver.
7. Aguarde revisão e ajuste o código conforme o feedback.

## Padrões de qualidade

- Evite misturar várias tarefas diferentes no mesmo Pull Request.
- Não remova funcionalidades sem explicar o motivo.
- Preserve o comportamento existente quando não fizer parte da tarefa.
- Se não conseguir testar uma mudança, informe isso claramente.
- Atualize a documentação quando o comportamento ou a forma de uso mudar.

## Observação sobre o projeto

O repositório atualmente contém um arquivo HTML identificado como painel de treino híbrido, embora o repositório se chame `painel-semanal`. Antes de fazer alterações funcionais, confirme com a pessoa responsável qual é o escopo correto do projeto.
