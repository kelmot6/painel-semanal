# Painel Semanal

## Conteúdo atual

Este repositório contém o arquivo HTML incluído a pedido do proprietário:

- `Coach_Hibrido_IA_SQLite_CORRIGIDO.html` — aplicação HTML independente identificada no próprio arquivo como um painel de treino híbrido.

## Como abrir

1. Abra o arquivo no GitHub e escolha **Download raw** (ou baixe o arquivo).
2. Salve-o no computador.
3. Abra o arquivo baixado em um navegador moderno, como Chrome, Edge ou Firefox.

## Atenção ao escopo

O repositório chama-se **Painel Semanal**, mas o arquivo publicado identifica-se como **Híbrido — Painel de Treino**. Ele foi incluído conforme solicitado, mas ainda não foi confirmado que seja o código-fonte do Painel Semanal. Antes de aceitar alterações funcionais, alinhe com o time qual é o projeto correto.

## Como contribuir em equipe

Leia [CONTRIBUTING.md](CONTRIBUTING.md) antes de começar. O fluxo recomendado é:

1. Registre a tarefa ou o bug em uma Issue.
2. Crie uma branch separada para a tarefa.
3. Faça commits pequenos, com mensagens claras.
4. Abra um Pull Request direcionado à branch `main`.
5. Peça uma revisão antes de integrar as alterações.

Use os modelos em `.github/` para Issues e Pull Requests.

## Estado das configurações de colaboração

Os arquivos de orientação estão no repositório. A visibilidade pública, os convites de colaboradores e a proteção obrigatória da branch `main` são configurações do GitHub e precisam ser conferidas em **Settings**. A existência de um modelo de Pull Request, por si só, não bloqueia alterações diretas na branch principal.

## Segurança

Nunca publique senhas, tokens, chaves de API, dados pessoais ou arquivos locais privados. Como o repositório será público, qualquer pessoa poderá visualizar e copiar o código.
